# InterstellarRaccoon.dev

Source code of my own personal webpage+portfolio

## Stack

- Vite
- Vue3
- Vitest
- TypeScript

## Useful commands
### Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Run Unit Tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```
